# Ironveil: Three Banners

Simulator perang faksi otonom (GM Observer) — modular web app, host di Netlify.
Lihat `requirement.md` untuk spesifikasi lengkap.

## Cara menjalankan lokal
- Buka folder ini di VS Code.
- Klik kanan `index.html` → **Open with Live Server**.

## Deploy
- Push ke GitHub, hubungkan repo ke Netlify (publish directory: `.`).
